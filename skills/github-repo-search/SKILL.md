# GitHub Repo Search & Skill Fetcher
Use `SkillManager.fetch_and_stage_skill(source)` or `POST /api/v1/skills/fetch` to pull open-source `SKILL.md` folders or Python tools from GitHub, audit their AST, and install them into `skills/`.
